## O5 testing
1. After selecting O5 as your pump, when activating a pod for the first time - the app will prompt you to sign in with Github
2. You must have the AndroidAPS repo forked to your Github account and have 2FA enabled on your github account to obtain an O5 certificate
3. Post in the Discord AAPS channel to give feedback or file an issue on Github: https://github.com/nightscout/AndroidAPS/issues
