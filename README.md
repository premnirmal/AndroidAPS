### Omnipod5 testing
1. Before building, request a test certificate granted to you by a Nightscout developer. You can reach out through the WeAreNotWaiting #omnipod5 thread, instructions on the discord thread in the wiki.
2. Place the credential file under the `pump/omnipod/omnipod5/main/assets/certificates/` folder. It **must** be placed in this folder prior to building, otherwise it will not successfully import.
3. Proceed to build the app with build instructions in the wiki.
4. Select Omnipod5 as your pump, and when prompted for a certificate, click the 'Import from assets' button to import the certificate.
5. Proceed with pod pairing.
